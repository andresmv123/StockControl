
# StockControl

Aplicación móvil de gestión de inventario desarrollada
como proyecto académico de Desarrollo Móvil Integral.

## Tecnologías

- Ionic
- Angular
- TypeScript
- Supabase
- Capacitor

## Funcionalidades

- Registro e inicio de sesión.
- Roles de administrador y empleado.
- Gestión de productos.
- Registro de entradas y salidas de inventario.
- Dashboard con estadísticas.
- Perfil de usuario.
- Conversión aproximada de MXN a USD.

## Control de versiones

El proyecto utiliza Git y GitHub con las ramas:

- main: versión estable.
- develop: integración de funcionalidades.
- feature/*: desarrollo de cambios específicos.
